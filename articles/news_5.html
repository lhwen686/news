深度解析

《紫毫 Hare》输入法展示了传统输入法技术与现代AI的融合。其核心技术原理基于开源的Rime引擎和雾凇拼音词库，针对移动触屏进行优化，如为小鹤双拼定制键盘布局，并引入了基于手指触碰落点和拼音构词规则的智能纠错机制，极大提升了盲打体验。在长句输入方面，通过筛选日常语料训练的“紫毫口语”模型，实现了接近大型模型的推断效果，同时支持轻量化部署，平衡了性能与资源占用。 在行业影响上，紫毫为Mac上鼠须管的资深用户提供了无缝迁移的解决方案，满足了小众但对输入体验有高要求的用户群。其“设备端完成拼音转换、纠错与学习”的设计，在数据隐私日益受重视的当下，构成强劲的竞争优势。此外，通过允许用户自备API密钥来启用“AI脚本”等增值服务，紫毫巧妙地将大型AI模型的强大能力集成到输入法中，既提供了翻译、润色、总结等高级功能，又规避了开发者直接部署大型AI服务的成本与合规风险，预示着一种“用户自带AI能力”的新兴商业模式。然而，区域限制和AI功能的使用门槛是其在更广阔市场推广时需要克服的挑战。

Original
平台：iOS / iPadOS 关键词：输入法、Rime、小鹤双拼 @路中南：我在 Mac 上用鼠须管（Rime）调教小鹤双拼多年，换回 iPhone 自带输入法时，固定键位与生硬的选词习惯总让人感到不顺手。iOS 端此前已有仓输入法（Hamster）与元书等 Rime 方案，仓输入法强调自定义上限与灵活配置，而新上架的《紫毫 Hare》则主打开箱即用，把默认体验调到了装好就能直接打字的程度。 紫毫底层基于 Rime 引擎与雾凇拼音词库，针对移动端触屏做了专门适配。除了 26 键与九宫格，它为小鹤双拼单独设计了键盘布局，键位上清晰标注了对应韵母，免去了初学者或偶尔遗忘键位时来回切图对照的麻烦。 而我一直以来希望在iOS上拥有的「双拼纠错」体验，终于在紫毫上得以一窥：智能纠错机制结合了手指触碰落点与拼音构词规则，单手盲打时若手指按偏了临近键位，紫豪也能较好地纠正并识别出整词。 长句输入方面，紫毫首次启动会自动下载一个约 6.8MB 的「紫毫口语」模型。该模型从万象模型中筛选日常聊天语料提炼而来，官方称长句推断效果接近约 400MB 的完整版。实际使用中，聊天时长句里的同音字判断比系统自带键盘更准一些；且该模型只在整句输入时介入，打两三个字的短语依然利落。 如果设备存储吃紧，可以切换为 1.9MB 的轻量版，也可换用完整万象、八股文语法模型；若偏好纯粹的传统码表，也可以直接在方案设置中将模型移除。 在打字习惯上，紫毫支持简繁输出（含台湾与香港标准繁体）、中英混输、Emoji 候选与快捷短语。对于 Rime 老用户，紫毫的词库格式与 Mac 端的鼠须管一致，支持直接导入个人配置方案与词库，电脑端积累多年的打字偏好可以直接迁移过来。 隐私方面，紫毫的拼音转换、纠错与习惯学习全部在设备端完成。应用内无广告、无需注册账号，即便在系统设置中不开「允许完全访问」也能正常打字，只是此时键盘无法读取主应用内的词库与同步数据。 输入功能本身全部免费，商业化采用一次性买断的紫毫 Pro，无订阅制。Pro 解锁的主要是增值功能： 一是「边写边译」，输入中文后稍作停顿，选中的译文可直接填入输入框，支持中英互译及日韩法德俄西等多门语言，iOS 26 起还能直接调用系统离线翻译免去自备密钥。 二是候选栏的「AI 脚本」，支持翻译、润色、总结与回复，填入自己的 API 密钥即可由设备直连对应 AI 服务（比如我的一个高频场景就是用 DeepSeek API 稍微润色一下苹果可怜的听写结果）；此外内购后还包含全部主题配色，以及用于多设备同步学习词、快捷短语与配置的 iCloud 同步功能。 目前紫毫的局限主要有两点：其一是首发地区不含中国大陆与欧盟，国区 App Store 暂时无法直接下载，需要使用外区 Apple 账号；其二是 AI 脚本与润色总结需要用户自备在线大模型 API 密钥，对普通用户来说有一道使用门槛，也可能产生额外的调用资费。当然还有一点是我的私心：若是默认引号能够改为直角引号就更美了。 如果你在 Mac 上习惯了鼠须管，又希望在 iPhone 上拥有省心、注重隐私且无需复杂配置的小鹤双拼体验，紫毫值得尝试。你可以在 App Store 免费下载紫毫 Hare，基础打字功能免费且无广告，进阶功能可通过一次性买断升级为紫毫 Pro（目前未上架国区，具体价格请参考所在地区 App Store）。
