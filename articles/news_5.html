深度解析

Notomo的核心价值在于其技术性地弥补了Apple备忘录作为系统原生应用的局限，将其从一个基础工具提升为功能强大的生产力中心。文章揭示了几个关键专业概念：首先，Markdown实时渲染和CJK别名支持，这是一种将轻量级标记语言转换为富文本的技术，极大提升了内容创建效率和跨平台兼容性，特别是对中文用户优化，体现了软件本地化深度。其次，快捷命令系统和效率面板的引入，如斜杠命令和全局搜索，是现代笔记工具必备的交互范式，通过键盘驱动的操作实现快速功能调用，显著加速了用户工作流。最关键的是其AI集成机制，Notomo不销售AI点数，而是提供原生AI服务关联和API嵌入，允许用户自由选择大型语言模型（LLM）和上下文长度。这意味着Notomo作为一个“AI代理”，连接用户数据与第三方AI服务，而非自建AI生态，为用户带来了极大的灵活性和成本控制，避免了AI服务的供应商锁定。这种开放的AI集成策略，不仅让备忘录获得智能辅助能力（如AI写作、Skill调用），也推动了原生应用生态的拓展与革新，彰显了AI赋能传统软件的巨大潜力，同时也刺激了原生系统应用在功能和开放性上向第三方工具看齐的趋势。

Original
平台：macOS 关键词：备忘录 @Vanilla：作为一款系统应用，Apple 对备忘录的重视程度在最近几次大版本更新中可见一斑。多平台实时同步、多用户协作编辑、完全免费、系统入口丰富等特性让备忘录应用占据了「得天独厚」的优势，这让我们在把备忘录作为主力笔记工具的同时，也对它的编辑器提出了更高的要求。 从我个人使用的痛点来说，备忘录不支持 Markdown 语法渲染、没有快捷命令系统、没有 AI 辅助（国行用户专享）等问题也不是一朝一夕能解决的，就算 Apple 有这个想法，也要等待下一次大版本更新了。Notomo 的出现，让备忘录应用在当下就拥有了更加强大的功能，让我更加巩固了把备忘录应用当做主力笔记应用的信心。 Notomo 的核心功能主要包括三个方面：一是快捷操作，二是效率面板，三是跨应用技能。接下去，我们一个个来讲。 首先，Notomo 让备忘录支持了 Markdown 实时渲染。只要你在备忘录编辑器中输入 Markdown 语法，Notomo 会将它实时转换为对应的富文本格式。如果你将 Markdown 文本直接粘贴到备忘录中，通过点击 # 符号附近的光标位置，也可以触发 Markdown 渲染。 另外，Notomo 的 Markdown 渲染功能对中文用户也非常友好，因为它支持了 CJK 别名，也就是说我们无需切换输入法，就可以通过 》》 生成笔记链接、 【】 生成待办、 ··· 生成代码块。在设置中，我们可以看到所有支持的 Markdown 渲染语法和 CJK 友好别名，并且两个功能都支持单独开关。 Notomo 让备忘录编辑器支持了行内工具栏，只需要选中任意文本就会出现工具栏，可以一键完成格式化、Skill 使用或者 AI 写作。 作为当代笔记工具的标配，斜杠命令也是备忘录原来缺失的一环，而 Notomo 正好补上了。通过输入 / 符号，我们就可以快速调用格式化、问 AI、插入表格、插入日期或者时间等操作，可以有效提高写作的效率。 备忘录应用本身不具备模板功能，但是 Notomo 支持把普通笔记打造成模板，方便我们一键插入高频使用使用的笔记格式。使用方法也很简单，只需在备忘录应用中新建一个名为「Templates」的文件夹，在这个文件夹中的所有笔记都会成为一个模板，在设置界面中可以进行管理。Notomo 还准备了 Daily Note 和 Meetings Notes 两个内置模板，可以直接添加使用。插入模板时，通过前面提到的斜杠命令就可以浏览所有模板，并完成一键使用。 其次，Notomo 为备忘录应用新增了两个效率面板。一个是 Quick Open，可以通过键盘快捷键 ⌘Command + O 来触发。这个面板可以让我们在备忘录应用中随时随地对文件夹或者笔记内容进行搜索，并且一键跳转到搜索结果；另一个是命令面板，可以通过键盘快捷键 ⌘Command + K 来触发。这个面板可以方便地搜索、调用一些常用的操作，比如说显示反向链接、将 Markdown 粘贴为富文本、复制深层链接、导出 PDF 等，实用性很高。 最后，Notomo 对备忘录的拓展能力没有局限在备忘录应用内，而是延伸到了其它应用中。你在备忘录中创建的文字 Skills 可以在其它应用中调用，比如说在邮件应用中撰写邮件时通过键盘快捷键 ⌥Option + ⌘Command + P 来触发 Skill 列表，选中想要的那个就可调用 AI 大模型来完成 Skill 中对应的指令。 另外一个全局功能则是搜索，这个功能就像 Spotlight 一样，可以让我们在全局状态下都可以直接搜索备忘录中的笔记并完成一键调整，触发的键盘快捷键是 ⌥Option + ⌘Command + O ，呼出的窗口和备忘录应用中的搜索窗口是一致的。 提到 Skills，就不得不提到 Notomo 的 AI 集成机制。Notomo 支持读取备忘录中的 Skills 文件夹中的笔记作为 Skills，调用 AI 大模型后可以读取笔记中的任意内容，包括全文、图片、选中文本等，在大模型完成修改后会显示修改的内容，一目了然，对比清晰，还可以一键替换或者插入。值得注意的是，Notomo 本身不卖 Credits 也不支持订阅，只提供了原生 AI 服务关联和 API 嵌入的功能，可以自由选择模型和上下文长度。 如果你是备忘录应用的重度使用者，或者打算把备忘录应用作为主力笔记工具，我真心推荐你尝试一下 Notomo 这款辅助工具，因为它把备忘录这款系统应用从「能用」提升到了「好用」的水准，和大多数第三方的笔记应用相比也毫不逊色。 Notomo 可以在官网免费下载，提供了 30 天试用。Notomo 只提供了一次性买断，价格是 19.99 美元，现在早鸟价是 12.99 美元，支持单台 Mac 电脑授权。
