Marked 3 代表了 Markdown 工作流中一个高度专业化的辅助工具概念。其核心专业逻辑在于“解耦”——将 Markdown 的编辑与预览、出版功能分开，专注于提供一个独立的、功能强大的渲染和导出管道。与许多集成式“所见即所得”编辑器不同，Marked 3 的技术原理是通过实时监听外部编辑器对 .md 文件的修改并同步刷新预览，从而支持几乎所有能保存 Markdown 文件的编辑器。这种实时同步、广泛的语法支持（包括流程图、数学公式）、以及深度的自定义渲染能力，使其成为一个高级的“呈现引擎”。

其行业影响体现在提升了 Markdown 在专业内容创作和出版领域的地位。对于需要创作长篇文档、技术手册、学术论文或电子书的用户，Marked 3 解决了传统编辑器在排版精度、高级语法渲染和多格式输出方面的局限。它将 Markdown 从一个简单的写作格式提升至一个可用于专业出版的工具链，尤其是在需要高质量 PDF、Word 或 EPUB 输出时。这种兼容性和专业级功能，增强了Markdown在技术写作、内容管理和学术出版等行业中的应用潜力，极大地优化了专业用户的写作和出版体验。

@ElijahLee：如果你经常使用 Obsidian、VS Code、Bear、Ulysses 或其他 Markdown 编辑器，Marked 3 可以说是一款非常独特的辅助工具。 它不是 Markdown 编辑器，而是一个专注于实时预览、校对、排版和导出的伴侣应用。

很多 Markdown 软件都是「编辑器 + 预览器」一体化，例如 Typora、iA Writer，在编辑时所见即所得。Marked 3 采取完全不同的思路，它允许在你熟悉的软件中写作，对 .md 文件进行编辑，而此时 Marked 3 会通过一个独立的窗口， 预览排版效果。并且它会实时监听 .md 文件的变化，一旦在编辑器中进行保存，Marked 3 实时刷新预览效果。

因此，它可以配合几乎所有编辑器使用，包括：Obsidian、VS Code、Scrivener、Ulysses 等等，只要能够保存 Markdown 文件的软件，都可以作为它的前端编辑器。

Marked 3 对 Markdown 的支持非常完整，几乎覆盖目前主流 Markdown 语法生态，包括CommonMark、GitHub Flavored Markdown（GFM）、MultiMarkdown、Kramdown 等等。它还能支持正确显示 Mermaid 流程图、MathJax、KaTeX 数学公式、CriticMarkup 等等。正如应用的宣传语，Marked 3 可以说是终极 Markdown 文件的预览工具。

高度的自定义能力，使得我们可以按照自己的需求重新定义 Marked 3 的整个渲染流程。应用的 Style Manager 提供 9种不同样式风格，自定义 Processor 可以选择 Markdown 语言和 HTML 格式，自定义转换规则（Custom Rules）可以定制样式、调整元数据等。这些功能对于高度专业的 Markdown 用户、博客作者、电子书作者等等非常有用。

强大的导出能力也是 Marked 3 的优点，它支持将 .md 文件导出为 PDF、HTML、DOCX、EPUB、RTF、TextBundle 等 9 种格式。第三代最大的升级之一，就是重新设计了 DOCX 导出和导入能力，支持保留批注、修订、数学公式、图片等。

Marked 3 并不是为了取代 Obsidian、Typora 或 VS Code，而是定位于它们之上的专业预览和出版工具。它最大的优势在于兼容几乎所有 Markdown 编辑器，并提供更完整的排版预览、校对分析、导出能力以及高度可定制的工作流。对于经常创作长文、技术文档或需要输出高质量 PDF、Word、EPUB 的用户来说，它能够显著提升 Markdown 写作体验。
