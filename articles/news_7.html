深度解析

这篇文章深入探讨了RWA（现实世界资产）代币化背后的金融基础设施演进。核心概念在于，RWA的规模化落地并非简单地将资产“上链”，而是需要一个涵盖资产发行（HIP）、交易流通（HTP）、支付结算（HSP）及合规的全套链上金融基础设施。许可链（如HSK Chain）在此扮演关键角色，作为连接传统金融机构合规需求与DeFi开放流动性的接口层，通过CeDeFi模式实现了持牌机构与去中心化协议之间的清晰分工，解决了机构进入和资产流动的两大挑战。 此外，文章前瞻性地触及AI Agent对金融体系的潜在影响，指出AI Agent的高频、小额、自动化交互模式将对现有支付系统构成挑战，并催生对AI Agent身份、信用和资产操作的全新基础设施需求。从行业影响来看，这预示着金融基础设施的竞争焦点正从单一的技术速度转向综合的生态系统构建能力。未来的赢家将是那些能够稳定连接分散资产、机构和资金，并促使其长期、有效运转的“金融港口”，而非仅仅是“更快的链”，这将深刻重塑全球金融格局，加速传统金融与Web3世界的融合。

Original
【编者按】当美股代币化的热潮正在将传统证券资产快速搬上链上，区块链与传统金融世界之间也在经历一场更深层的基础设施演进。市场关注的重点，正在从如何将资产“搬上链”，转向如何让这些资产在链上真正流通、参与金融活动。作为国际金融中心，香港长期承担连接资本与商业活动的枢纽角色，而链上世界也正在寻找新的"金融港口"。这背后所反映的，或许并不只是资产形态的变化，更是一场金融基础设施的演进。围绕 RWA 规模化落地的现实挑战、链上金融基础设施的建设逻辑，以及 AI Agent 等新型经济主体可能带来的金融变革，FT中文网专访了 HashKey 集团商业拓展负责人兼 On-Chain 事业群首席运营官 Rachel Qiu，尝试从行业实践的角度，理解下一阶段链上金融基础设施将如何演进。 FT中文网： 过去几年，RWA 从一个相对前沿的概念，逐渐进入金融机构和大型企业的实际探索阶段。与此同时，市场也开始意识到，把资产“搬到链上”可能只是第一步。您认为，RWA 真正走向规模化，行业需要补齐哪些基础设施？ Rachel：我认为，RWA 的确正在经历一个重要变化：行业关注的重点，正在从“如何把资产上链”，转向“资产上链之后如何真正运行”。 过去很多人理解 RWA，首先想到的是把现实资产映射成一个 Token。但现实资产与加密原生资产最大的区别在于，它并不是天然存在于链上的。以一项债券、一笔贸易应收账款或一份电子提单为例，在进入链上之前，首先需要解决资产权属、法律效力、合规准入和信息披露等问题；资产上链之后，还需要继续解决交易、流动性、支付、结算以及存续期管理。 这也是为什么我们看到，RWA 的发展正在推动链上基础设施从单点工具走向系统化建设。资产发行只是开始，后面还需要有交易场所、流动性机制、支付和结算网络，以及能够连接链上和链下的合规体系。 HashKey On-Chain 所构建的链上金融基础设施就是来源于对行业变化的观察。 我们最近发布了 HIP（HashKey Issuance Platform）、HTP（HashKey Trading Platform） 和 HSP（HashKey Settlement Platform） 三个平台。HIP 的"七步上链"平台主要解决资产如何进入链上，HTP 解决资产进入市场之后如何交易和流动，HSP 则进一步连接支付与结算。它们分别对应资产进入、资产流通和资金结算环节，构成一条相对完整的链上金融链路，让资产、资金和金融活在链上动持续运转起来。 我们一直在布局一套让现实资产、机构资本和商业活动能够稳定进入链上运行的基础设施体系。 FT中文网： 在这套链上金融基础设施里面，公链到底承担什么角色？ Rachel： 在很多人的视角里，公链是一个技术接口。HSK Chain 过去在市场上也更多被认知为一条基于以太坊的二层公链，这个认知并没有错，但在 HashKey 整个链上金融基础设施的建设过程中，我们对它的定位已经发生了变化。我更倾向于这样理解 HSK Chain 是连接许可环境与开放市场、传统机构与 DeFi 流动性的接口层。 向内，它连接 HashKey 积累的牌照网络、银行合作、机构客户和合规服务；向外，它连接开发者、DeFi 协议和全球链上资金。两端打通之后，HashKey On-Chain 真正试图解决的问题才能成立：在不放弃合规和风险边界的前提下，把现实资产带入更开放的金融网络。 FT中文网：那么资产上链之后，流动性到底怎么解决？ Rachel： RWA 规模化过程中必须回答两个问题：机构为什么敢进来，以及资产进来之后为什么能够流动。 刚刚提到的，如 HSK Chain 在内的许可链首先解决的是信任和责任问题，金融机构需要明确参与者身份、资产责任、数据权限与风险边界。让银行、资管机构和大型企业，能够在身份可识别、权限可管理、风险可隔离的环境下完成资产发行、交易和结算。但许可链不是终点。资产如果始终停留在封闭网络中，虽然可以完成确权和机构间流转，却难以获得更广泛的资金来源、交易深度和价格发现。 为了打通链上流动性我们引入 了Morpho 等 DeFi 协议，做了 CeDeFi的尝试 ，并计划进一步连接 HashKey Exchange 体系，解决的正是机构进入之后，资产与资金如何真正活跃起来的问题。 CeDeFi 现实的含义，不是在中心化与去中心化之间寻找一个模糊的中间状态，而是让两套体系形成更清晰的分工：由持牌机构解决身份、合规、托管和法币入口，由 DeFi 解决交易效率、资产组合和开放流动性。一端把真实资产带进来，另一端把资金和流动性接上去。 只有两端同时成立，RWA 才可能从一批分散的发行项目，发展为一个持续运转的金融市场。无论是代币化股票、债券，还是其他现实世界资产，真正决定其能否规模化的，都不仅是“能不能发行”，而是能不能形成完整的链上金融活动闭环。 FT中文网：除了 RWA，AI Agent 也正在成为金融科技领域的重要讨论方向。未来如果 AI Agent 开始自主调用服务、管理资金甚至参与交易，现有金融基础设施是否能够承接这种变化？ Rachel： 我们认为 AI Agent 是下一阶段需要提前布局的方向，但它真正进入商业闭环还需要时间。 AI Agent 带来的变化，不只是出现了新的支付需求，而是交互方式的整体变化——高频、小额、自动化。这与传统支付体系的结算周期和成本结构存在明显错配；现有合规框架也缺乏针对 AI Agent 的可验证身份账户体系。这两个障碍不解决，AI Agent 很难真正进入商业闭环。 不过，我们此前落地的“eCandle 项目”让我们看到了 AI 自主支付的雏形。这个项目推出了一款独立光伏储能设备，用户通过手机扫码，使用 USDC 稳定币进行微额实时支付，款项到账后设备即时通电。整个过程基于我刚才提到的 HSP 多链结算协议完成，传统支付体系根本无法覆盖这类微额高频场景。 当然，从基础设施角度，我们认为还需要提前为 AI Agent 构建一套覆盖身份、信用与资产的完整框架——身份层解决"它是谁、代表谁行动"，信用层解决"它值不值得被信任"，资产与金融操作层则让 AI Agent 不只能完成支付，还能参与更复杂的金融场景。 FT中文网： 从更长周期来看，您认为链上金融基础设施的竞争最终会体现在哪些方面？ Rachel： 我用一个比喻来回答这个问题。我们看到大航海时代真正改变世界的并不只是新航线的开辟，而是围绕航行逐渐形成的港口、贸易、保险和结算网络。港口连接的不只是船只，更连接了资产、资金与商业活动。 今天，区块链与传统金融之间正在发生某种类似的变化。公链打开了新的空间，但只有发行、交易、流动性、支付、结算与合规网络逐渐成熟，这个空间才可能真正成为金融市场的一部分。 从这个角度看，未来行业竞争的重点可能不只是“谁拥有一条更快的链”，而是谁能够把分散的资产、机构和资金连接起来，并让它们能够长期、稳定地运行。 HashKey On-Chain 现在所做的，就是将过去高度定制、依赖多方协调的业务，逐步沉淀为可以重复使用的产品和流程，让发行、交易、支付和结算不再彼此割裂。这条路注定更慢、更重，也更难形成短期热度。但从现实金融的业务逻辑看，它几乎是 RWA 规模化无法绕开的路径。 新航线决定人们能不能抵达，而基础设施决定这片新世界能不能真正繁荣。 （本文仅代表作者观点。责任编辑邮箱：[email protected]）
